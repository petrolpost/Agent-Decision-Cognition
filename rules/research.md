# Research Rules

This file contains the lightweight rules that apply to research artifacts in this repository. `AGENTS.md` remains the authoritative project-level guidance.

## Evidence Before Abstraction

Record what was observed before naming a general mechanism.

## Minimal Change

An experiment should change as little as possible between conditions so that causal interpretation remains possible.

## Counterfactual Awareness

For every finding, state what alternative explanation could account for the observation when practical.

## No Silent Normalization

Do not normalize away model corrections, rejected options, uncertainty, or contradictory behavior merely to make an artifact cleaner.

## Finding Status

Use explicit status when a claim is recorded:

- `validated` — supported by the current experiment set;
- `rejected` — current evidence argues against the claim;
- `open` — insufficient evidence;
- `hypothesis` — proposed but not yet tested.

These labels describe the state of evidence, not permanent truth.
