# Concepts

This directory contains working concepts used to describe observations. A concept in this directory is **not automatically a required system entity**.

Current concepts under investigation:

- Decision
- Alternative
- Evidence
- Context
- Memory
- Decision Environment
- Capability

## Working Rule

A concept should remain descriptive until experiments show that an explicit representation or mechanism provides value beyond simpler alternatives.

In particular, `Decision` should be treated as an external reconstruction of observable Agent behavior unless evidence supports a stronger interpretation. Do not assume that the model internally contains a discrete object with the same name.
