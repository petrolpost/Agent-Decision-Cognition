# Research Questions

This directory tracks the questions currently under investigation. These are questions, not commitments to particular system components.

## A. Intent → Runtime Decision

How much next-step decision capability can an Agent exercise when given an Intent, relevant Context, and available capabilities without a predefined execution path?

## B. Runtime Decision vs. Predefined Orchestration

Under what task structures and decision environments is runtime decision-making useful, and where does explicit orchestration provide more reliable control?

The comparison should focus on where decision control resides, rather than assuming either approach is inherently better.

## C. Decision Environment

What observable characteristics of an environment affect an Agent's ability to decide at runtime?

## D. Capability Discovery

When does an Agent need explicit capability discovery rather than having sufficient capabilities exposed through Prompt, Context, or Tool descriptions?

## E. Decision / Alternative / Evidence / Context

Can these concepts improve observation and analysis of Agent behavior without falsely implying that they are internal model objects?

## F. Memory and Decision

What distinguishes preserving or recalling a previous decision from reasoning or deciding in the current context?

## G. Human-facing Representation

What representation lets people inspect, question, correct, and accumulate Agent decisions without overstating what can be known about the model's internal process?

## Current Discipline

Each question should lead to a minimal experiment before it leads to a new architecture component.
