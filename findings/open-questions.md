# Open Questions

This file records unresolved questions that should influence future experiments.

- How much Intent-driven Runtime Decision capability is available without explicit decision structures?
- Which characteristics of a Decision Environment make runtime decision more or less reliable?
- When does Capability Discovery add value beyond sufficiently expressive Context and capability descriptions?
- Can Decision / Alternative / Evidence representations improve human inspection without implying unsupported claims about model internals?
- What is the practical boundary between Decision preservation, recall, reasoning, and deciding?
- Which human-facing representations help people challenge and correct Agent decisions rather than merely explain them after the fact?
